# План демонстрации

Перед показом выбери тестового бота и отдельную SQLite. Запиши проверяемый
коммит, режим запуска и дату прогона. Команды установки и запуска есть
в [инструкции по окружению](environment.md).

Костя проверяет запуск, базу и журнал. Андрей проверяет команды и ответы
в чате. Владимир проверяет переходы, бой и мини-игры. Перед показом запусти
`python -m pytest -q`. Этот прогон работает с заглушками и дополняет
проверку в чате.

| Сценарий | Действие и ожидаемый результат | FS или HLD | Результат |
| --- | --- | --- | --- |
| Начало и продолжение | Два игрока запускают бота. После выбора и повторного `/start` каждый видит свою сцену. | F_Tg_1–2, F_Sess_12–13 | |
| Справка и неизвестная команда | `/help` показывает команды. Несуществующая команда не меняет игру. | F_Tg_3–4 | |
| Переход и кнопки | Выбор открывает нужную сцену. После смены сцены старая кнопка не меняет игру. | F_Tg_5–9, F_Eng_16–19 | |
| Перезапуск | `/restart` спрашивает подтверждение. «Нет» оставляет прохождение, «Да» начинает новое. | F_Tg_10–11 | |
| Флаги | Сделай выбор, который ставит флаг, и проверь доступность следующего варианта. После нового прохождения проверь сброс флага. | F_Flags_20–22 | |
| Концовки | Открой концовку, проверь описание и счетчик в `/endings`. При первом открытии появляется уведомление. Повторное открытие не дает дубль. Проверь, что обе кнопки начинают новое прохождение и сохраняют прогресс. «Концовки» дополнительно показывает список. | F_End_27–29 | |
| Чекпоинт | Сделай два сохранения на разных сценах. `/load` возвращает последнее сохранение, у нового игрока без чекпоинта начинает игру с первой сцены. | F_CP_33–36 | |
| Парашют | В сцене 44 «Выпутаться из парашюта» открывает сцену 48. | Уточнение к карте, A-N1 | |
| Таймер сцены 45 | Сохранись на сцене 45. Повторный `/start` сохраняет срок, а `/load` дает новые пять минут. Дождись тайм-аута и проверь переход к концовке в сцене 46. | Уточнение к карте, A-N2 и В-N1 | |
| Бой | Проверь все три действия, изменение HP, победу и поражение. Сохранение и загрузка во время боя недоступны. | F_Battle_23–26, HLD 4 | |
| Подготовка Drunk | Нажатая кнопка исчезает, последняя оставшаяся запускает игру. | F_Drunk_43 | |
| Drunk | Проверь перемешивание букв, три раунда и ошибочный ответ. | F_Drunk_37–44, NF_Drunk_39 | |
| Lost | Введи верный код до срока. В отдельных попытках проверь неверное число и истечение времени, в том числе при открытом подтверждении перезапуска. | F_Lost_45–49 | |
| Отказ БД | На отдельном экземпляре сделай базу временно недоступной. Проверь предупреждение, игру в памяти, блокировку сохранения и запись после восстановления. | F_Sess_14–15 | |
| Остановка | Останови процесс и проверь запись в журнале. Закрытие задач и ресурсов дополнительно проверь тестами. | HLD 6.4–6.5 | |

До боя и мини-игр в ручном сценарии дойди по карте. Фикстуры можно
использовать отдельно, если проверяешь конкретную ветку без длинного
прохождения. Пасхалку можно показать дополнительно, без раскрытия кода
в общем плане.

Если шаг воспроизводимо падает, заведи Issue. Укажи коммит, окружение,
действия, ожидаемый и фактический результат, требование и ответственного.
После исправления повтори проверку и добавь ссылку на PR. Результаты в таблицу
записываем после реального прогона. Для весенней сдачи тест-планы согласуем
с преподавателем и оформляем отчеты отдельно.

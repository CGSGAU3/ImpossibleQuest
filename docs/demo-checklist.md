# Демонстрация квест-бота

Это план ручного прогона, а не отчет о проведенной демонстрации. Заполняем
результаты после проверки согласованного тестового бота. Боевого бота и чужие
сессии не используем. Секреты и содержимое окружения в отчет не копируем.

Перед прогоном все три роли проверяют, что установлены зависимости и проходит
`python -m pytest -q`. Костя готовит тестовое окружение, Андрей проверяет команды
и сообщения, Владимир проверяет игровые исходы. Зафиксировать ветку и коммит
проверяемой сборки. Порядок запуска указан в общем README.

| Сценарий | Что проверить | Требования | Результат и замечания |
|---|---|---|---|
| Начало и продолжение | /start создает сессию, повторный /start продолжает ее; другой игрок получает отдельную сессию | F_Tg_1–2, F_Sess_12–13 | |
| Команды | /help показывает команды; неизвестная команда не меняет сцену | F_Tg_3–4 | |
| Обычный выбор | Видны текст и доступные кнопки, выбор переводит к нужной сцене | F_Tg_5–9, F_Eng_16–19 | |
| Старая кнопка | После нового экрана нажатие старой кнопки отклоняется, состояние не меняется | F_Tg_7 | |
| Перезапуск | Сначала показано подтверждение; «Нет» оставляет прохождение, «Да» начинает заново | F_Tg_10–11 | |
| Концовка | Концовка регистрируется один раз, /endings показывает описание и счетчик; restart сохраняет открытые концовки | F_End_27–29 | |
| Чекпоинт | /save заменяет прежний чекпоинт, /load восстанавливает сцену и флаги; без чекпоинта начало с первой сцены | F_CP_33–36 | |
| Бой | Три действия, изменение HP, победа и поражение; save/load в бою запрещены | F_Battle_23–26, HLD 4 | |
| Подготовка Drunk | Нажатие убирает выбранную кнопку, последняя оставшаяся запускает игру | F_Drunk_43 | |
| Drunk | Три раунда, перемешивание букв не чаще раза в секунду; ошибка завершает игру, правильные ответы дают победу | F_Drunk_37–44, NF_Drunk_39 | |
| Lost | Числовые кнопки, ввод кода, успех до срока; неправильное число и истечение срока дают поражение | F_Lost_45–49 | |
| Перезапуск во время Lost | Запрос подтверждения не останавливает срок игры | F_Lost_47–49 | |
| Отказ БД | В контролируемом тесте есть предупреждение, прохождение продолжается в памяти, save/load запрещены; после восстановления прогресс записывается | F_Sess_14–15 | |
| Остановка | Нет оставшихся задач таймера, ресурсы приложения закрываются | HLD 6.4–6.5 | |

До боя, Drunk и Lost нужно дойти по карте. Автоматические проверки могут
устанавливать исходное состояние через фикстуры, в демонстрации нельзя выдавать
такой подготовленный переход за обычное прохождение игроком.

## Найденные ошибки

На каждую воспроизводимую ошибку создаем отдельную Issue. Не заполняем журнал
выдуманными дефектами. Минимальный шаблон:

- Что не работает.
- Окружение и коммит.
- Шаги воспроизведения.
- Что ожидалось.
- Что получилось.
- Требование FS и тест, если он есть.
- Приоритет, серьезность и ответственный по подсистеме.
- Ссылка на исправление и результат повторной проверки.

Задачу не закрываем только потому, что внесен код. Другой участник повторяет
шаги и подтверждает результат. Скриншоты и логи прикладываем без токенов и
личных данных посторонних игроков.
